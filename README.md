# Dhakka Local

A wobbly-ragdoll party game set in a packed Mumbai local. Push, dropkick and throw everyone out of the doors; the last one inside wins.

**Play:** https://yousufkhn.github.io/dhakka-local/

- Plays in the phone browser (landscape) or on a computer (WASD, Space, J, K).
- **Dosto ke saath (online):** one phone creates a room and shares the 4-letter code or WhatsApp link; up to 6 friends join, empty seats get bots. The host phone runs the match, so keep it on and the app open.
- Single file: `index.html` (Three.js + cannon-es + PeerJS from jsDelivr; all models, textures and sounds are generated in code).
- `dhakka-local-2d.html` is the earlier 2D version.
